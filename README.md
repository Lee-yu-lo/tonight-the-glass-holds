## 玩法

- **走**：四个嫌疑人各守一个房间，信息必须走过去才拿得到
- **问**：暖光（金）/ 冷光（蓝）/ 熄灯（灰）三种提问方式
- **等**：熄灯后沉默 8 秒，对方才多说那半句
- **落笔**：在出口写下一个词，四种结局
